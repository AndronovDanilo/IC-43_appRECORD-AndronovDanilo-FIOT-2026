## Структура репозиторію
```
├── index.html        # Головна сторінка звітного порталу з бічним меню ЛР1-ЛР9
├── css/
│   └── style.css     # Адаптивні стилі інтерфейсу звітного документа
├── js/
│   └── script.js     # Інтерактивна логіка перемикання робіт та тематичних вкладок

```

## Функціонал звітного документа
- **Бокове меню навігації:** швидкий вибір лабораторних робіт (ЛР №1 – ЛР №9);
- **Лабораторна робота №1:**
  1. Тема, мета та офіційні посилання на репозиторії та GitHub Pages;
  2. Опис предметного середовища та бізнес-логіки веб-застосунку;
  3. Структура головної сторінки (HTML-код);
  4. Код, жива візуалізація та теоретичний довідник по таблицях;
  5. Код, жива візуалізація та теоретичний довідник по формах;
  6. Код, жива візуалізація та теоретичний довідник по списках;
  7. Код, візуалізація та теоретичний довідник по зображеннях;
  8. Змістовні висновки до виконаної роботи.
- **Лабораторна робота №2:**
  1. Тема, мета, офіційні посилання на живі сторінки репозиторіїв (резюме, застосунок, звіт);
  2. Селектори тегу (HTML, CSS, візуалізація);
  3. Селектори класу (HTML, CSS, візуалізація);
  4. Селектори ідентифікатора (HTML, CSS, візуалізація);
  5. Інші селектори: універсальний, дочірній, сусідній, селектори атрибутів;
  6. Стильове оформлення: Шрифти, Текст, Таблиці (Zebra, Hover), Фон, Контур, Списки, CSS Просунутий;
  7. Стилізація та структура Резюме (посилання на живу сторінку);
  8. Висновки до ЛР №2;
  9. Відповіді на контрольні запитання викладача.
- **Лабораторна робота №3:**
  1. Тема, мета, офіційні посилання на живі сторінки репозиторіїв та резюме;
  2. Завдання №1: Адаптивна верстка власного сайту (Flexbox сітка, бургер-меню, медіа-запити @media з логічними операторами, десктоп/планшет/мобільний);
  3. Завдання №2: Таблична верстка макету (Варіант 1 — фіксована 800px та гумова 100%);
  4. Завдання №2: Блокова верстка макету на float (Варіант 2 — фіксована та гумова, clear: both);
  5. Завдання №3: Flexbox верстка макету (Варіант 1 — головна та поперечна осі, flex-grow/shrink);
  6. Висновки до ЛР №3;
  7. Відповіді на контрольні запитання викладача (8 теоретичних запитань).
